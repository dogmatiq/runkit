An event stream is an ordered list of events. The engine appends the events that aggregate and integration handlers record. For each process and projection handler, a node consumes each event stream, which means that it dispatches the stream's events to the handler. Each of those handlers has a checkpoint offset for each event stream, which is the offset of the next event that it expects to handle.
